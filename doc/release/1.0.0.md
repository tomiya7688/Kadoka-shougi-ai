# Kadoka Shougi AI 1.0.0 リリース到達条件

この文書はKadoka Shougi AI 1.0.0のリリース判定基準です。日本語版を正本とします。各項目は、対象となるリリース候補（RC）の成果物と、その成果物を使った確認記録に基づいて判定します。Issueの完了やソースツリー上のテスト成功だけでは、リリース条件を満たした証拠になりません。

## 判定対象と記録

リリース判定では次の情報を同じ記録に残します。

- バージョン、コミットID、配布候補artifactの識別子とSHA-256
- 対象OSと実行環境
- 自動テストのworkflow/run URL、結果レポート
- 手動確認の実施者、日時、チェック結果、証跡の保存先
- 未達項目、既知の不具合、リリース可否の判断

各条件の状態は「未実施」「成功」「失敗」で記録します。成功は、該当するRC成果物を使って期待結果を確認できた場合に限ります。未実施または失敗が残る場合はリリースを停止します。

## リリース停止条件

次のいずれかに該当した場合は1.0.0をリリースしません。

- 必須到達条件に「未実施」または「失敗」が残る。
- 自動テストが別の成果物やソースツリーだけを対象とし、リリース候補artifactを検証していない。
- 失敗した必須検査の原因、修正、再実行結果を追跡できない。
- 手動チェックの証跡、実施者、対象artifactが記録されていない。
- 初心者向けモデルの品質基準が数値または再現可能な判定手順として公開されていない。
- 未解決の不具合により、通常対局、学習、作成モデルの利用、履歴出力、主要UI操作のいずれかが阻害される。
